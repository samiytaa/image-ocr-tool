# 代号鸢家具识别工具

一个基于 React + Vite 的网页工具，用多模态大模型识别《代号鸢》家具截图，并整理成可导出到 Excel 或 Wiki 表格的数据。

## 当前功能

- 单张家具截图识别，提取家具名称、用处、描述、获取方式、品质、占格数
- 批量识别多张图片，自动分批处理并显示进度、成功数、失败数
- 根据 3 个名称预设，自动生成同一家具的 3 条名称变体
- 自动推导 `家具打造 / 家具染色` 获取字段，减少手动整理
- 识别结果自动暂存到本地 `localStorage`
- 支持保存、读取、删除名称预设方案
- 支持编辑、覆盖重名家具、删除单条结果、清空全部结果
- 支持 Markdown 预览、复制为制表符表格、导出 `.xlsx`
- 内置 GitHub Pages 工作流，可直接从 `main` 分支重新部署

## 技术栈

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- `xlsx` 用于导出 Excel

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:3000`。

## 使用说明

1. 打开页面后，先在顶部设置中确认多模态接口配置可用。
2. 在“男主家具颜色”区域填写 3 个名称后缀，或读取已保存方案。
3. 上传单张或多张家具截图。
4. 执行识别后，检查右侧表单并按需修改。
5. 将结果保存到暂存区后，统一导出为 Excel 或复制到表格工具。

## 部署

- 仓库使用 [`.github/workflows`](.github/workflows) 中的 GitHub Pages 工作流自动构建部署
- 推送到 `main` 分支后会自动执行 `npm ci` 和 `npm run build`
- 当前仓库已移除自定义域名配置，默认应使用 GitHub Pages 地址
